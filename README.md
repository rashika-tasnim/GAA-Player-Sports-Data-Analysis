# MySQL Database Design and SQL Reporting Project

This project presents a data analytics workflow based on a real-world sports participation dataset. The original work involved relational database modelling in MySQL Workbench and dashboard reporting in Apache Superset. Because the original dataset contains player, guardian, organization, and team-level information, the raw data is not shared publicly.

This public portfolio version documents the database design, SQL analysis logic, and planned Power BI dashboard using anonymized, aggregated, or synthetic sample data.

## Tools Used
- MySQL Workbench
- SQL
- Apache Superset
- Excel

## Project Focus
- Sports participation analysis
- Relational database design
- Fact and dimension modelling
- SQL-based reporting
- Dashboard design for non-technical stakeholders

## Data Privacy
The original dataset included potentially sensitive participant and guardian-level records. For this reason, this repository does not include the original raw dataset. Public examples are shown only using anonymized, synthetic, or aggregated data.
